# JavaScript Objects Basics - User Profile Project

This is a JavaScript project that demonstrates how to use objects to store and display structured data.


## Project Goal

The goal of this project is to learn:
- How to create objects in JavaScript
- How to access object properties
- How to store real-world data using objects
- How to display object data using DOM manipulation

## What I learned

- How JavaScript objects work
- How to use key-value pairs
- How to access object properties using dot notation
- How to represent real-world data (user, car, etc.)
- How to update HTML content dynamically


## How it works

This project shows two examples:

### 1. User Object
Displays:
- name
- age
- job

### 2. Car Object
Displays:
- brand
- model
- year

The output is shown in the browser using DOM manipulation.
